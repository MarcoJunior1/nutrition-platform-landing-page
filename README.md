# CalorIA Verde — Landing Page para Profissionais

Landing page de apresentação da **plataforma nutricional CalorIA Verde** para **nutricionistas e profissionais de saúde**.

## ✨ Destaques

- Hero com proposta de valor e chamadas para ação
- Seções de benefícios, planos, **FAQ** e CTA final
- Animações de *reveal* ao rolar a página, cursor personalizado e textura de ruído
- Identidade visual verde/lima/creme com tipografia **Space Grotesk**
- 100% estática (HTML + CSS + JS em um único arquivo)

## 🚀 Como usar

Abra `index.html` no navegador ou publique em GitHub Pages, Netlify ou Vercel.
